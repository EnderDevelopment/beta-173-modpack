# Dream of Fog

Dream of Fog is a Minecraft mod that recreates the Beta 1.7.3 experience in a modern version. It focuses on no hunger, no sprinting, no enchanting, no brewing, no end dimension, retro nether, beta worldgen, and beta textures while keeping the anvil.

## Install

1. Download the mod file from the releases section.
2. Place the mod file in the `mods` folder of your Minecraft instance.
3. Launch Minecraft with the Fabric loader installed.

## Use

1. Launch Minecraft with the mod installed.
2. Enjoy the Beta 1.7.3 experience in a modern version.
